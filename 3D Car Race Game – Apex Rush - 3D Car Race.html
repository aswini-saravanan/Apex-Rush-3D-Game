# 🏎️ Neon Rush **A fast, 3D-style arcade racing game that runs in your browser.** Drive from the START gate to the FINISH line, dodge traffic, and set a time on the leaderboard. Built from scratch with JavaScript and the HTML5 Canvas API, using a custom pseudo-3D rendering engine. No game engine and no 3D library. ## ✨ Features - **Pseudo-3D road engine:** perspective projection with curves, hills, rumble strips, lane markings, and a parallax skyline. - **Smooth driving feel:** a fixed-timestep physics loop (60 updates per second) with eased steering and speed-based steering response. - **Traffic:** 45 AI cars share the road, with collision detection, speed loss on impact, and camera shake. - **Free off-road driving:** leaving the asphalt never slows or traps the car. - **Complete game flow:** home page, 3-2-1-GO countdown, START and FINISH gates with checkered lines, a live progress bar, and a finish screen. - **In-game controls:** a bottom dashboard with Quit (back to home) and Restart, plus a pause menu on `Esc`. - **Leaderboard:** the top 5 race times, saved in the browser and shown after you cross the finish line. - **Visual style:** a neon home page and a bright daytime race scene, with a HUD for speed, time, and race progress. --- ## 🎮 Controls | Key | Action | | --- | --- | | `W` / `↑` | Accelerate | | `S` / `↓` | Brake | | `A` `D` / `←` `→` | Steer | | `Esc` or `P` | Pause / resume | | `R` | Restart the race | | `Enter` | Start the race from the home or finish screen | --- ## 🚀 Getting Started 1. Each frame, the segments in front of the car are projected to screen coordinates and drawn back to front. Curves come from accumulating the horizontal offset of each segment, and hills from interpolating segment heights. - **Fixed timestep with a separate render loop:** physics always advances in 1/60 s steps while drawing runs on `requestAnimationFrame`, so the game behaves the same on fast and slow machines. - **Steering and curve force:** steering input is smoothed with an exponential ease, and the car is pushed outward on curves in proportion to speed and curve strength. - **Collision detection:** traffic cars are matched against the player by distance along the track and lateral lane offset. - **Persistent leaderboard:** results are sorted and stored with `localStorage`, with safe fallbacks if storage is unavailable. --- ## 🧰 Tech Stack - JavaScript (game logic and rendering) - HTML5 Canvas 2D API - HTML and CSS --- ## 🗺️ Roadmap - [ ] Port the game to Unity (C#) with true 3D physics using WheelColliders - [ ] Opponent AI that follows a racing line - [ ] Multiple tracks, car selection, and tuning options - [ ] Engine sound that changes with speed - [ ] Online leaderboard --- ## Credits - **Game design, programming, and UI:** Aswini S - **Home page artwork:** _add the source and credit here, or replace it with your own artwork before sharing publicly._
